**根目录**：`D:\大二限修课感知作业`
**规矩**：根目录永远只有下面这 7 样。以后要改，只做**替换或删除**，绝不新增第二份（不出 `_v2`、`_新`、`_最终` 这类文件）。

## 7 样东西

| # | 名字 | 是什么 | 什么时候看 |

## code\

| 文件 | 作用 | 要不要自己跑 |
|---|---|---|
| `geom.py` | 计算层：解单应、像素转毫米、测距 | 不用，被下面三个 import |
| `measure_table.py` | 测长宽的主程序 | 要跑 |
| `calib_k.py` | 解相机内参 K（加分项） | 可选 |
| `analyze.py` | 误差统计 + 出图 | 有数据后要跑 |
| `.venv\` | Python 运行环境 | 不用管，别删 |
| `__pycache__\` | Python 自动生成的缓存 | 可随时删，不影响运行 |

## data\

| 路径 | 内容 |
|---|---|
| `01.jpg … 25.jpg` | 25 张照片（自己放进去） |
| `meta.csv` | 可选：每张的距离/俯角，填了才能按条件分组 |
| `results\` | 程序输出：标注图、俯视校正图、`result.csv`、`picks.json`、`stats\`、`figures\`、`K.txt` |

## 三条命令

```bat
cd /d D:\大二限修课感知作业
code\.venv\Scripts\python.exe code\measure_table.py --selftest
code\.venv\Scripts\python.exe code\measure_table.py --batch "data/*.jpg"
code\.venv\Scripts\python.exe code\analyze.py
```

嫌命令长：先跑 `code\.venv\Scripts\activate.bat`，之后直接打 `python`。
